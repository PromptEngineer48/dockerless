# dockerless

Video production pipeline for a YouTube explainer on the paper
**[Dockerless: Environment-Free Program Verifier for Coding Agents](https://arxiv.org/abs/2606.28436)**,
narrated with a cloned voice via open-source Qwen3-TTS.

See [`video/README.md`](video/README.md) for the full pipeline
(script → slides → cloned-voice TTS → MP4).
